Obtenir les applications

Une petite application installe toutes les autres et les tient à jour. Toutes celles de la série Reader's et les quatre qui la suivent sont dans sa liste.

Reader's Installer and Updater

v1.0.2GPL-3.0com.freedomfighter.readersinstaller

Ouvrez-le une fois : chaque application est dans la liste, à un toucher de l'installation. Ensuite les mises à jour arrivent toutes seules, celles de l'installateur comprises. Quand une application existe aussi pour l'ordinateur, sa page dans l'installateur y mène. Version modifiée d'Obtainium (GPL-3.0), sans lien avec ses auteurs ; il peut suivre n'importe quelle autre application de la même façon.

Télécharger l'installateur (APK) Code source

Trois étapes

  1. Sur le téléphone, touchez Télécharger l'installateur ci-dessus, puis ouvrez le fichier. Android demande une fois d'autoriser le navigateur à installer des applications : acceptez.
  2. Ouvrez Reader's Installer. Les applications sont dans la liste : touchez-en une, puis Installer. Android demande une fois d'autoriser l'installateur à installer des applications.
  3. C'est tout. Les mises à jour sont cherchées en arrière-plan ; sur Android 12 et suivants, elles s'installent sans rien demander pour les applications que l'installateur a installées lui-même.

Pour ARM 64 bits, soit presque tous les téléphones et tablettes depuis 2017. Une application installée auparavant depuis F-Droid ou un APK demande une confirmation, une fois, puis suit.

Trois autres façons, si vous préférez vous passer de l'installateur. Les fichiers sont identiques et portent la même signature quelle que soit la voie choisie : on peut changer d'avis plus tard sans rien désinstaller.

F-Droid (les mises à jour arrivent toutes seules)

  1. Installez le client F-Droid (Droid-ify ou Neo Store conviennent aussi).
  2. Ajoutez le dépôt : touchez le bouton ci-dessous depuis le téléphone, ou scannez le code depuis un ordinateur.
  3. Actualisez, cherchez l'application, installez. F-Droid tient ensuite toutes les applications à jour.

Obtainium (mises à jour directement depuis GitHub)

Obtainium installe et met à jour les applications depuis leurs versions publiées sur GitHub, sans magasin intermédiaire. Avec Obtainium sur le téléphone, touchez le bouton Obtainium de n'importe quelle application ci-dessous. Le lien ouvre Obtainium directement et ne passe par aucune page tierce.

Le fichier APK (dernier recours : pas de mises à jour)

Chaque application a aussi un lien APK. Installée ainsi, une application ne se met jamais à jour : il faudrait revenir ici à chaque nouvelle version. À réserver à un essai, ou à un appareil où ni F-Droid ni Obtainium ne peuvent tourner.

La série Reader's

Un téléphone qui se lit comme une page. Des applications en noir et blanc, texte seul : pas d'icônes, pas de couleurs, pas de cartes, pas de compte. Le launcher affiche des mots ; l'agenda, les tâches, les notes, les livres et les flux se lisent comme un journal ; Reader's Detox tient les réseaux sociaux à distance. Dans l'esprit du Light Phone, sur n'importe quel Android. Toutes sont dans la liste de l'installateur, en anglais, français, allemand, espagnol, portugais et russe. La plupart fournissent aussi des widgets standard, noir et blanc, pour n'importe quel autre launcher.

Sur l'ordinateur

Reader's Calendar, Tasks, Notes et Scanner existent aussi pour Windows, macOS et Linux, et Reader's Podcasts pour Linux. Le bouton de téléchargement est sur la fiche de chaque application, plus haut ; dans l'installateur, la page de l'application mène à sa version pour l'ordinateur.

Debian / Ubuntu / Pop!_OS / Mint : le dépôt apt

Les cinq applications pour l'ordinateur sont aussi dans un petit dépôt apt : elles se mettent à jour avec le reste du système.

sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://funkypitt.github.io/apt-repo/funkypitt.gpg | sudo tee /etc/apt/keyrings/funkypitt.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/funkypitt.gpg] https://funkypitt.github.io/apt-repo stable main" | sudo tee /etc/apt/sources.list.d/funkypitt.list
sudo apt update && sudo apt install readers-calendar readers-notes readers-tasks readers-scanner readers-podcasts

Arch Linux : le dépôt de chaque application contient un PKGBUILD. Détails sur funkypitt.github.io/apt-repo.

Windows et macOS : la première ouverture

Reader's Calendar, Reader's Notes et Reader's Tasks existent aussi en .exe pour Windows et en .dmg pour macOS, dans la page de téléchargement de chaque application : un seul fichier, rien à installer, pas de Python à prévoir. Ce sont de petites applications libres sans certificat payant, alors le système s'en méfie une fois — une seule.

Windows : un panneau bleu « Windows a protégé votre ordinateur » apparaît à la première ouverture. Informations complémentaires › Exécuter quand même.

macOS : ouvrez le .dmg — « apple-silicon » pour un Mac M1 ou plus récent, « intel » pour un Mac plus ancien —, glissez l'application dans Applications, puis clic droit sur l'application › Ouvrir › Ouvrir. Un double-clic, à ce moment-là, dit seulement que l'application ne peut pas être ouverte. Ensuite elle s'ouvre comme les autres.
