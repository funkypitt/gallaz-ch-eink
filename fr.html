E-ink & détox numérique

Outils open-source pour la lecture longue, l'écoute et le bien-être numérique. Contraste élevé, sans pub, sans compte, sans algorithme. Conçus pour les écrans à encre électronique et un usage intentionnel. Depuis 2026, la série Reader's : un téléphone entier en noir et blanc, texte seul.

Obtenir les applications Android

Trois façons, par ordre de préférence. Les fichiers sont identiques et portent la même signature quelle que soit la voie choisie : on peut changer d'avis plus tard sans rien désinstaller.

1 — F-Droid (recommandé : les mises à jour arrivent toutes seules)

  1. Installez le client F-Droid (Droid-ify ou Neo Store conviennent aussi).
  2. Ajoutez le dépôt : touchez le bouton ci-dessous depuis le téléphone, ou scannez le code depuis un ordinateur.
  3. Actualisez, cherchez l'application, installez. F-Droid tient ensuite toutes les applications à jour.

2 — Obtainium (mises à jour directement depuis GitHub)

Obtainium installe et met à jour les applications depuis leurs versions publiées sur GitHub, sans magasin intermédiaire. Avec Obtainium sur le téléphone, touchez le bouton Obtainium de n'importe quelle application ci-dessous. Le lien ouvre Obtainium directement et ne passe par aucune page tierce.

3 — Le fichier APK (dernier recours : pas de mises à jour)

Chaque application a aussi un lien APK. Installée ainsi, une application ne se met jamais à jour : il faudrait revenir ici à chaque nouvelle version. À réserver à un essai, ou à un appareil où ni F-Droid ni Obtainium ne peuvent tourner.

La série Reader's

Un téléphone qui se lit comme une page. Des applications en noir et blanc, texte seul : pas d'icônes, pas de couleurs, pas de cartes, pas de compte. Le launcher affiche des mots ; l'agenda, les tâches, les notes, les livres et les flux se lisent comme un journal ; Reader's Detox tient les réseaux sociaux à distance. Dans l'esprit du Light Phone, sur n'importe quel Android. Toutes sont dans le dépôt F-Droid ci-dessus, en anglais, français, allemand, espagnol, portugais et russe. La plupart fournissent aussi des widgets standard, noir et blanc, pour n'importe quel autre launcher.

Debian / Ubuntu / Pop!_OS / Mint : le dépôt apt

Reader's Calendar, Reader's Notes et Reader's Tasks pour Linux sont aussi dans un petit dépôt apt : ils se mettent à jour avec le reste du système.

sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://funkypitt.github.io/apt-repo/funkypitt.gpg | sudo tee /etc/apt/keyrings/funkypitt.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/funkypitt.gpg] https://funkypitt.github.io/apt-repo stable main" | sudo tee /etc/apt/sources.list.d/funkypitt.list
sudo apt update && sudo apt install readers-calendar readers-notes readers-tasks

Arch Linux : le dépôt de chaque application contient un PKGBUILD. Détails sur funkypitt.github.io/apt-repo.

Windows et macOS : la première ouverture

Reader's Calendar, Reader's Notes et Reader's Tasks existent aussi en .exe pour Windows et en .dmg pour macOS, dans la page de téléchargement de chaque application : un seul fichier, rien à installer, pas de Python à prévoir. Ce sont de petites applications libres sans certificat payant, alors le système s'en méfie une fois — une seule.

Windows : un panneau bleu « Windows a protégé votre ordinateur » apparaît à la première ouverture. Informations complémentaires › Exécuter quand même.

macOS : ouvrez le .dmg — « apple-silicon » pour un Mac M1 ou plus récent, « intel » pour un Mac plus ancien —, glissez l'application dans Applications, puis clic droit sur l'application › Ouvrir › Ouvrir. Un double-clic, à ce moment-là, dit seulement que l'application ne peut pas être ouverte. Ensuite elle s'ouvre comme les autres.
