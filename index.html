Sobre

v0.1.0 · GPL-3.0 · app.sobre.player

Lecteur audio YouTube par abonnement. Écouter ses chaînes comme un podcast — pas de vidéo, pas de miniatures, pas d'algorithme, pas de Shorts, pas de commentaires. Interface 100 % texte. Flux chronologique, lecture en arrière-plan, vitesse réglable, chapitres, téléchargements hors-ligne, export/import OPML. Vidéos de moins de 5 minutes masquées automatiquement.

Social Detox

v1.0.0 · GPL-3.0 · com.parentcontrol.socialblocker.detox

VPN local bloquant les requêtes DNS de YouTube, Instagram et TikTok. Pas de proxy, pas de certificat — seul le DNS est intercepté. Toggles par plateforme, plages horaires, démarrage automatique. Friction auto-imposée, pas un contrôle parental.

Installation

Option 1 — F-Droid (recommandé)

  1. Installer le client F-Droid.
  2. Toucher « Ajouter dans F-Droid » ci-dessus — confirmer l'adresse pré-remplie.
  3. Rafraîchir le catalogue, chercher l'application, installer.

Option 2 — APK direct

  1. Activer l'installation depuis des sources inconnues.
  2. Toucher « Télécharger l'APK » sous l'application voulue.
  3. Ouvrir le fichier et confirmer. Pas de mises à jour automatiques.

Extensions Chrome

PageTurn

v1.0.0 · Manifest v3 + bookmarklet

Convertit les pages web en lecture paginée — comme un livre. Changement de page instantané (essentiel sur e-ink). Détection automatique sur Substack, Medium, WordPress, Ghost, Dev.to, etc. Supprime pubs, sidebars, pop-ups et commentaires. Navigation clavier, swipe et tap.

Télécharger (ZIP) Code source

Social Media Blocker

v1.0 · Chrome / Firefox (Manifest v3)

Bloque les réseaux sociaux et sites de vidéo. Pour débloquer, résoudre cinq problèmes de maths de difficulté croissante — conçu pour casser le réflexe sans rendre les sites totalement inaccessibles. Aucune collecte de données.

Télécharger (Chrome) Télécharger (Firefox) Code source

Installation

  1. Télécharger et décompresser le ZIP.
  2. Chrome : chrome://extensions/ → mode développeur → Charger l'extension non empaquetée → sélectionner le dossier.
  3. Firefox : about:debugging#/runtime/this-firefox → Charger un module temporaire → choisir manifest.json.

Linux

Tinta4PlusU

ThinkBook Plus Gen 4 IRU · Python

Interface Linux pour l'écran e-ink couleur du Lenovo ThinkBook Plus Gen 4 IRU. Supporte GNOME, KDE Plasma, Cinnamon, XFCE (X11 et Wayland). Routage entre OLED et panneau e-ink, rétroéclairage et luminosité via le contrôleur embarqué.

Télécharger (ZIP) Code source

eInk Reader

GPL-3.0 · Python / PyQt5

Lecteur d'e-books pour l'écran e-ink du ThinkBook. Mode page uniquement, envoie des commandes clear-ghosts à Tinta4PlusU après chaque page. EPUB, MOBI, PDF, DJVU, FB2, CBR/CBZ, Markdown, texte brut.

Télécharger (ZIP) Code source

Installation

Ubuntu 24.04+ (ou dérivés). Désactiver le Secure Boot pour l'accès au contrôleur embarqué.

git clone https://github.com/funkypitt/Tinta4Plus-Universal.git
cd Tinta4Plus-Universal
sudo bash installer.sh

eInk Reader s'installe de la même façon — voir son README.
