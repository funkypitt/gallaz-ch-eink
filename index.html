Pour les écrans à encre électronique

Sept projets pensés pour les liseuses, tablettes et ordinateurs à encre électronique : trois lecteurs Android, une extension navigateur, deux outils de détox numérique, et le pilote Linux d'un ordinateur double écran. Lecture longue, contraste élevé, navigation au tap, sans publicités ni comptes.

Lecteur ePub Magazine

v0.2.5 · GPL-3.0 · ua.acclorite.book_story.debug

Lecteur ePub adapté aux numéros quotidiens de presse et de magazine. Détecte les ePubs de presse à l'ouverture, pagine la table des matières avec une carte par article (rubrique, titre, image optionnelle), et affiche chaque article dans une vue à défilement vertical. Navigation par tap (gauche/droite tournent la page, centre affiche les contrôles). Calibré sur les ePubs produits pour NZZ, 24 heures, Courrier International et The Economist.

Source des ePubs : compatible avec les ePubs générés par la fonction Récupérer les actualités de Calibre (Calibre > Récupérer les actualités > choisir une recette). Configurer une recette pour son journal préféré et l'envoyer vers l'appareil chaque matin : la table des matières et les articles sont reconnus sans configuration supplémentaire.

Installation (Android)

Option 1 — Via F-Droid (recommandé, mises à jour automatiques)

  1. Installer le client F-Droid s'il n'est pas déjà présent.
  2. Toucher « Ajouter dans F-Droid » ci-dessus depuis l'appareil Android. F-Droid ouvre la page d'ajout du dépôt avec l'adresse et l'empreinte pré-remplies — confirmer.
  3. Mettre à jour le catalogue, puis chercher l'application souhaitée et l'installer comme n'importe quelle autre.

Ajout manuel si le lien ne s'ouvre pas : dans F-Droid > Paramètres > Dépôts > +, coller l'adresse et l'empreinte indiquées plus haut.

Option 2 — APK direct (installation ponctuelle)

  1. Activer l'installation depuis des sources inconnues pour le navigateur (Paramètres > Applications > le navigateur > Installer des applis inconnues).
  2. Toucher « Télécharger l'APK » sous l'application choisie.
  3. Ouvrir le fichier téléchargé et confirmer l'installation. Les mises à jour ne sont pas automatiques avec cette méthode.

Extension navigateur

PageTurn

v1.0.0 · Extension Chrome (Manifest v3) + bookmarklet

Extension Chrome et bookmarklet qui convertissent les pages web en lecture paginée — comme un livre. Changement de page instantané, sans animation (essentiel pour l'encre électronique). Détection automatique du contenu sur Substack, Medium, WordPress, Ghost, Dev.to, Hashnode, Blogger, Hugo, Jekyll. Suppression des barres de navigation, publicités, sidebars, formulaires d'abonnement et commentaires. Navigation au clavier, au swipe ou au tap sur les bords. Aucune collecte de données.

Code source Télécharger (ZIP)

Installation (PageTurn)

Option 1 — Bookmarklet (le plus simple, fonctionne partout)

Glisser le bouton ci-dessous dans la barre de favoris :

PageTurn

Cliquer ensuite sur ce favori depuis n'importe quel article web pour passer en mode paginé. Cliquer à nouveau (ou appuyer sur Échap) pour quitter.

Option 2 — Extension Chrome (chargement manuel)

  1. Télécharger le ZIP ci-dessus, ou cloner git clone https://github.com/funkypitt/pageturn.git.
  2. Ouvrir chrome://extensions/, activer le mode développeur.
  3. Cliquer sur Charger l'extension non empaquetée et sélectionner le dossier décompressé.
  4. Sur un article, cliquer l'icône PageTurn ou appuyer sur Alt+P.

Raccourcis une fois actif : → / Espace page suivante, ← précédente, Échap sortir. Sur écran tactile : swipe ou tap sur les bords.

Détox numérique

Couper YouTube, Instagram et TikTok à la racine — Android et navigateur. Pas de contrôle parental, pas de mot de passe : ce sont des outils auto-imposés. Le frottement vient du fait de devoir consciemment ouvrir l'application pour les désactiver, pas d'un secret à deviner. Naturellement complémentaires d'une vie de lecture sur encre électronique.

Social Detox (Android)

v1.0.0 · GPL-3.0 · com.parentcontrol.socialblocker.detox

VPN local Android qui intercepte les requêtes DNS pour YouTube, Instagram et TikTok et les bloque silencieusement. Seul le DNS (UDP 53) passe par l'interface virtuelle : pas de proxy en amont, pas de certificat, le reste du trafic n'est pas touché. Toggle par plateforme, plages horaires d'autorisation quotidiennes optionnelles (ex. 6-8,18-22), démarrage automatique au boot, service au premier plan pour qu'Android ne le tue pas. À combiner avec VPN permanent dans les paramètres réseau pour une protection stricte.

Fork de SocialBlocker sans la barrière de mot de passe — pensé comme outil auto-imposé.

Social Media Blocker (Chrome)

v1.0 · Extension Chrome / Firefox (Manifest v3)

Extension navigateur qui bloque les sites de médias sociaux et de partage vidéo. Pour débloquer, il faut résoudre cinq problèmes de mathématiques de difficulté croissante : la friction est conçue pour casser le réflexe automatique d'aller sur ces sites, sans les rendre totalement inaccessibles. Aucune collecte de données, aucune connexion réseau sortante.

Code source Télécharger (Chrome ZIP) Télécharger (Firefox ZIP)

Installation (Social Detox Android)

Comme les autres applications Android plus haut : soit ajouter le dépôt F-Droid une fois (mises à jour automatiques), soit télécharger l'APK directement. La première fois, Android demandera l'autorisation pour le VPN local — c'est normal et nécessaire ; tout reste sur l'appareil.

Installation (Social Media Blocker — extension)

  1. Télécharger le ZIP Chrome ou Firefox ci-dessus, puis le décompresser.
  2. Sur Chrome : ouvrir chrome://extensions/, activer le mode développeur, cliquer Charger l'extension non empaquetée et choisir le dossier décompressé.
  3. Sur Firefox : ouvrir about:debugging#/runtime/this-firefox, cliquer Charger un module temporaire, choisir le manifest.json du dossier.

Pour débloquer un site, l'extension présente cinq problèmes de mathématiques. Réussir les cinq lève le blocage jusqu'au prochain redémarrage du navigateur.

Linux — ordinateur double écran

Tinta4PlusU

Linux · ThinkBook Plus Gen 4 IRU

Interface graphique Linux pour piloter l'écran à encre électronique couleur du Lenovo ThinkBook Plus Gen 4 IRU. Fork universel du Tinta4Plus original avec prise en charge de GNOME (X11 / Wayland), KDE Plasma (X11 / Wayland), Cinnamon et XFCE, plus un installateur système. Gère le routage entre l'OLED 2880×1800 et le panneau couleur 2560×1600 à encre électronique, le rétroéclairage et la luminosité via le contrôleur embarqué.

Code source Télécharger (ZIP)

Installation (Tinta4PlusU)

Base : Ubuntu 24.04 LTS ou ultérieur (Xubuntu, Kubuntu, Linux Mint compatibles).

  1. Désactiver le Secure Boot dans le BIOS (Security > Secure Boot > Disabled). Nécessaire pour accéder au contrôleur embarqué (rétroéclairage).
  2. Cloner et installer : 
    git clone https://github.com/funkypitt/Tinta4Plus-Universal.git
cd Tinta4Plus-Universal
sudo bash installer.sh
  3. Choisir option 2 (scripts Python — recommandée, plus facile à déboguer et mettre à jour). L'installateur détecte l'environnement de bureau et installe les dépendances nécessaires.

Configurations testées : GNOME et XFCE sur X11. Les autres sessions (GNOME Wayland, KDE Plasma, Cinnamon) sont prises en charge mais moins éprouvées.
