Getting the apps

One small app installs all the others and keeps them up to date. Every app of the Reader's family and the four that follow it are in its list.

Reader's Installer and Updater

v1.0.2GPL-3.0com.freedomfighter.readersinstaller

Open it once: every app is in the list, one tap from being installed. After that the updates arrive by themselves, the installer's own included. When an app also exists for the desktop, its page in the installer links to it. A modified version of Obtainium (GPL-3.0), not affiliated with its authors; it can follow any other app the same way.

Download the installer (APK) Source

Three steps

  1. On the phone, tap Download the installer above, then open the file. Android asks once to let the browser install apps: allow it.
  2. Open Reader's Installer. The apps are in the list: tap one, then Install. Android asks once to let the installer install apps.
  3. That is all. Updates are looked for in the background; on Android 12 and later they install silently for the apps the installer installed itself.

For 64-bit ARM, which is nearly every phone and tablet since 2017. An app installed earlier from F-Droid or an APK asks once for confirmation, then follows.

Three other ways, if you would rather not use the installer. The files are identical and carry the same signature whichever way you choose, so you can change your mind later without uninstalling anything.

F-Droid (updates arrive by themselves)

  1. Install the F-Droid client (Droid-ify or Neo Store work too).
  2. Add the repository: tap the button below on the phone, or scan the code from a computer.
  3. Refresh, search for the app, install. F-Droid then keeps every app up to date.

Obtainium (updates straight from GitHub)

Obtainium installs and updates apps from their GitHub releases, with no store in between. With Obtainium on the phone, tap the Obtainium button of any app below. The link opens Obtainium directly and goes through no third-party page.

The APK file (last resort: no updates)

Each app also has an APK link. Installed this way, an app never updates: you would have to come back here for every new version. Use it to try an app, or on a device where neither F-Droid nor Obtainium can run.

The Reader's family

A phone that reads like a page. Black-and-white, text-only apps: no icons, no colours, no cards, no account. The launcher shows words; the calendar, tasks, notes, books and feeds read like a newspaper; Reader's Detox keeps the social networks out. In the spirit of the Light Phone, on any Android. All of them are in the installer's list, in English, French, German, Spanish, Portuguese and Russian. Most also provide standard black-and-white widgets for any other launcher. Black and white suits an e-ink phone or tablet as well as any screen: that is where these apps began.

Android v1.1.2Desktop v1.0.4MITcom.freedomfighter.readersscanner

Reader's Night Filter

Android v1.2.0Desktop v1.0.1MITcom.freedomfighter.readersnight

One switch turns the screen gray, as warm as the phone allows, and dim, then puts everything back as it was. It sits in the quick settings, in a widget and in the app. It asks for a permission given once from a computer, with one command shown in the app; no root. Android does not let an app remove blue entirely: the tint stops at the phone's warmest setting.

On the desktop and in the browser, where an app can remove blue entirely: gray and amber at the brightness you choose, on GNOME, KDE Plasma, Windows, macOS (these two in preview) and in Chrome and Brave. Details under On the desktop.

Debian / Ubuntu / Pop!_OS / Mint: the apt repository

The five desktop apps are also in a small apt repository, so they update with the rest of the system.

sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://funkypitt.github.io/apt-repo/funkypitt.gpg | sudo tee /etc/apt/keyrings/funkypitt.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/funkypitt.gpg] https://funkypitt.github.io/apt-repo stable main" | sudo tee /etc/apt/sources.list.d/funkypitt.list
sudo apt update && sudo apt install readers-calendar readers-notes readers-tasks readers-scanner readers-podcasts

Arch Linux: each app's repository has a PKGBUILD. Details at funkypitt.github.io/apt-repo.

Windows and macOS: the first opening

Reader's Calendar, Reader's Notes and Reader's Tasks also come as an .exe for Windows and a .dmg for macOS, on each app's download page: one file, nothing to install, no Python to think about. They are small free applications without a paid certificate, so the system distrusts them once — once only.

Windows: a blue "Windows protected your PC" panel appears the first time. More info › Run anyway.

macOS: open the .dmg — "apple-silicon" for an M1 Mac or later, "intel" for an older one — drag the app onto Applications, then right click on the app › Open › Open. A double click at that point only says the app cannot be opened. Afterwards it opens like any other.

Tools for the computer

Three projects for Linux, for people who open a terminal now and then.

Traduction toolkit: translating, subtitling and dubbing videos with AI

PythonLinux, NVIDIA GPU

Independent Python scripts that translate, subtitle, dub, summarise and cut clips from a video in any language: WhisperX for the words, a local language model (Ollama, the default, no API key) or Claude for the translation, Qwen3-TTS for the voices, the original voice cloned if you wish. A graphical interface, a .deb package and a browser extension drive it all without the command line. Needs an NVIDIA GPU with about 12 GB (24 GB for everything local); an AMD/ROCm fork exists for the Ryzen AI Max (Strix Halo). Documentation in French.

Source and installer AMD fork

Quai

GPL-3.0RustCOSMIC

A two-column side dock for the COSMIC desktop, in the style of Ubuntu's Unity launcher: pinned apps on the left, open ones on the right, each tile lit with the colour of its icon. Click, middle click, right click and drag do what you expect; 130 px wide, the proportions of two Unity launchers.

Source

epub2md

MITPythonpip install epub2md-ai

Converts EPUB books to clean Markdown for AI tools (NotebookLM, Claude, ChatGPT): the metadata as a header, images extracted and relinked, no line wrapping, whole folders at once, pure Python.

Browser extensions

Two extensions for Chrome and Firefox, loaded from a folder. The browser version of Reader's Night Filter comes with its desktop package.

PageTurn

Reads web pages as a book: pages instead of scrolling, turned with no animation — what e-ink needs. Recognises articles on Substack, Medium, WordPress, Ghost, Dev.to and more, and removes ads, sidebars, pop-ups and comments.

Social Media Blocker

v1.0Chrome / Firefox (Manifest v3)

Blocks social media and video sites. To get through, solve five maths problems of rising difficulty: enough to break the reflex, not enough to lock you out. Collects nothing.

Download (ZIP, Chrome and Firefox) Source code

Installation

  1. Download and extract the ZIP.
  2. Chrome: chrome://extensions/ → Developer mode → Load unpacked → select folder.
  3. Firefox: about:debugging#/runtime/this-firefox → Load Temporary Add-on → pick manifest.firefox.json (Social Media Blocker) or manifest.json.
