E-ink & digital detox

Open-source tools for long-form reading, listening, and digital wellbeing. High contrast, no ads, no accounts, no algorithm. Designed for e-ink screens and intentional use. Since 2026, the Reader's family: a whole phone in black and white, text only.

Getting the Android apps

Three ways, in order of preference. The files are identical and carry the same signature whichever way you choose, so you can change your mind later without uninstalling anything.

1 — F-Droid (recommended: updates arrive by themselves)

  1. Install the F-Droid client (Droid-ify or Neo Store work too).
  2. Add the repository: tap the button below on the phone, or scan the code from a computer.
  3. Refresh, search for the app, install. F-Droid then keeps every app up to date.

2 — Obtainium (updates straight from GitHub)

Obtainium installs and updates apps from their GitHub releases, with no store in between. With Obtainium on the phone, tap the Obtainium button of any app below. The link opens Obtainium directly and goes through no third-party page.

3 — The APK file (last resort: no updates)

Each app also has an APK link. Installed this way, an app never updates: you would have to come back here for every new version. Use it to try an app, or on a device where neither F-Droid nor Obtainium can run.

The Reader's family

A phone that reads like a page. Black-and-white, text-only apps: no icons, no colours, no cards, no account. The launcher shows words; the calendar, tasks, notes, books and feeds read like a newspaper; Reader's Detox keeps the social networks out. In the spirit of the Light Phone, on any Android. All of them ship from the F-Droid repository above, in English, French, German, Spanish, Portuguese and Russian. Most also provide standard black-and-white widgets for any other launcher.

Debian / Ubuntu / Pop!_OS / Mint: the apt repository

Reader's Calendar, Reader's Notes and Reader's Tasks for Linux are also in a small apt repository, so they update with the rest of the system.

sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://funkypitt.github.io/apt-repo/funkypitt.gpg | sudo tee /etc/apt/keyrings/funkypitt.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/funkypitt.gpg] https://funkypitt.github.io/apt-repo stable main" | sudo tee /etc/apt/sources.list.d/funkypitt.list
sudo apt update && sudo apt install readers-calendar readers-notes readers-tasks

Arch Linux: each app's repository has a PKGBUILD. Details at funkypitt.github.io/apt-repo.

Windows and macOS: the first opening

Reader's Calendar, Reader's Notes and Reader's Tasks also come as an .exe for Windows and a .dmg for macOS, on each app's download page: one file, nothing to install, no Python to think about. They are small free applications without a paid certificate, so the system distrusts them once — once only.

Windows: a blue "Windows protected your PC" panel appears the first time. More info › Run anyway.

macOS: open the .dmg — "apple-silicon" for an M1 Mac or later, "intel" for an older one — drag the app onto Applications, then right click on the app › Open › Open. A double click at that point only says the app cannot be opened. Afterwards it opens like any other.
