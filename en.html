ePub Magazine reader

v0.2.5 · GPL-3.0 · ua.acclorite.book_story.debug

ePub viewer tuned for daily newspaper and magazine issues. Auto-detects magazine ePubs on open, paginates the table of contents with one card per article (section, title, optional cover image), and renders each article in a vertically-scrolled view. Tap-driven navigation (left / right turn the page, centre toggles the toolbar). Calibrated against the ePub formats produced for NZZ, 24 heures, Courrier International, and The Economist.

Where the ePubs come from: compatible with the ePubs produced by Calibre's Fetch news feature (Calibre > Fetch news > pick a recipe). Set up a recipe for your favourite paper and push the output to your device every morning — the table of contents and articles are recognised with no further configuration.

Installation (Android)

Option 1 — via F-Droid (recommended, auto-updates)

  1. Install the F-Droid client if you don't already have it.
  2. From the Android device, tap “Add to F-Droid” above. F-Droid opens its "add repository" page with the address and fingerprint pre-filled — confirm.
  3. Refresh the catalog, then search for the app you want and install it like any other.

Manual fallback if the deep link doesn't work: in F-Droid > Settings > Repositories > +, paste the address and fingerprint shown above.

Option 2 — direct APK (one-shot install)

  1. Allow installs from unknown sources for your browser (Settings > Apps > your browser > Install unknown apps).
  2. Tap "Download APK" under the app you want.
  3. Open the downloaded file and confirm the install. Updates are not automatic with this method.

Browser extension

PageTurn

v1.0.0 · Chrome extension (Manifest v3) + bookmarklet

Chrome extension and bookmarklet that turn scrollable web pages into paginated reading — like a book. Instant page turns with no animation (essential on e-ink). Auto-detects article content on Substack, Medium, WordPress, Ghost, Dev.to, Hashnode, Blogger, Hugo, Jekyll. Strips navigation bars, ads, sidebars, newsletter pop-ups, and comments. Keyboard, swipe, and edge-tap navigation. Zero data collection.

Source code Download (ZIP)

Installation (PageTurn)

Option 1 — bookmarklet (simplest, works anywhere)

Drag the button below to your bookmarks bar:

PageTurn

Click it from any article page to switch into paginated mode. Click again (or press Esc) to exit.

Option 2 — Chrome extension (load unpacked)

  1. Download the ZIP above, or clone git clone https://github.com/funkypitt/pageturn.git.
  2. Open chrome://extensions/ and enable Developer mode.
  3. Click Load unpacked and select the extracted folder.
  4. On any article, click the PageTurn icon or press Alt+P.

Shortcuts once active: → / Space next page, ← previous, Esc exit. On a touchscreen: swipe or tap the edges.

Digital detox

Cut YouTube, Instagram, and TikTok at the source — Android and browser. No parental control, no password: these are self-imposed tools. The friction is the conscious act of opening the app to disable it, not a secret to guess. A natural companion to a reading-on-e-ink lifestyle.

Social Detox (Android)

v1.0.0 · GPL-3.0 · com.parentcontrol.socialblocker.detox

Local Android VPN that intercepts DNS queries for YouTube, Instagram, and TikTok and silently drops them. Only DNS (UDP 53) is routed through the virtual interface — no upstream proxy, no certificate, the rest of your traffic is untouched. Per-platform toggles, optional daily allow-windows (e.g. 6-8,18-22), auto-start on boot, foreground service so Android doesn't kill it. Combine with Always-on VPN in network settings for stricter enforcement.

Fork of SocialBlocker with the password gate removed — designed as a self-imposed tool.

Social Media Blocker (Chrome)

v1.0 · Chrome / Firefox extension (Manifest v3)

Browser extension that blocks social media and video-sharing sites. To unblock, solve five math problems of increasing difficulty: the friction is designed to break the automatic "open Twitter" reflex without making the sites entirely inaccessible. Zero data collection, no outbound network traffic.

Source code Download (Chrome ZIP) Download (Firefox ZIP)

Installation (Social Detox Android)

Same as the other Android apps above: either add the F-Droid repository once (auto-updates) or download the APK directly. On first launch Android will ask for local-VPN permission — that's expected and required; nothing leaves the device.

Installation (Social Media Blocker — browser extension)

  1. Download the Chrome or Firefox ZIP above and extract it.
  2. On Chrome: open chrome://extensions/, enable Developer mode, click Load unpacked, and select the extracted folder.
  3. On Firefox: open about:debugging#/runtime/this-firefox, click Load Temporary Add-on, and pick the manifest.json inside the folder.

To unblock a site, the extension presents five math problems. Solving all five lifts the block until the next browser restart.

Linux — dual-display laptop

Tinta4PlusU

Linux · ThinkBook Plus Gen 4 IRU

Linux GUI for driving the color e-ink display of the Lenovo ThinkBook Plus Gen 4 IRU. Universal fork of the original Tinta4Plus with support for GNOME (X11 / Wayland), KDE Plasma (X11 / Wayland), Cinnamon, and XFCE, plus a system installer. Handles routing between the 2880×1800 OLED and the secondary 2560×1600 color e-ink panel, plus frontlight and brightness via the embedded controller.

Source code Download (ZIP)

Installation (Tinta4PlusU)

Base: Ubuntu 24.04 LTS or later (Xubuntu, Kubuntu, Linux Mint all work).

  1. Disable Secure Boot in the BIOS (Security > Secure Boot > Disabled). Required for embedded-controller access (frontlight).
  2. Clone and install: 
    git clone https://github.com/funkypitt/Tinta4Plus-Universal.git
cd Tinta4Plus-Universal
sudo bash installer.sh
  3. Pick option 2 (Python scripts — recommended, easier to debug and update). The installer detects your desktop environment and installs the necessary dependencies.

Tested configurations: GNOME and XFCE on X11. Other sessions (GNOME Wayland, KDE Plasma, Cinnamon) are supported but less battle-tested.

eInk Reader

Linux · GPL-3.0 · Python / PyQt5

E-ink-optimised e-book reader — a Lector fork tuned for the ThinkBook Plus Gen 4 IRU eInk display. Page mode only (no scroll; single-page or two-up), and after every page turn it talks to the Tinta4PlusU helper daemon via a Unix socket and sends a clear-ghosts command to wipe ghosting artefacts. Works fine without Tinta4PlusU too — page turns still happen, just without the explicit eInk clear pulse. Supported formats: EPUB, MOBI, PDF, DJVU, FB2, CBR/CBZ comics, Markdown, plain text.

Source code Download (ZIP)

Installation (eInk Reader)

Tinta4PlusU is strongly recommended alongside — it's what responds to the clear-ghosts signal after each page turn. Without it, eInk Reader is still usable but ghosting can build up.

  1. Clone and run the installer: 
    git clone https://github.com/funkypitt/eink-reader.git
cd eink-reader
sudo bash installer.sh
  2. The installer drops the files in /opt/eink-reader, adds an eink-reader command in /usr/local/bin, and creates a desktop-menu entry. Uninstall: sudo bash installer.sh --uninstall.
  3. Launch from the application menu, or from a terminal: eink-reader.

Dependencies: Python 3.6+, PyQt5, beautifulsoup4, lxml, PyMuPDF (for PDF), python-djvulibre optional (for DJVU). The installer handles them.
